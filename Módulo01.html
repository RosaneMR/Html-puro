Básico do HTML

A tag é usado para criar um elemento. Por exemplo, tag p no início do parágrafo,fim tag.

Os atributos são propriedades que uma tag pode ter.

HTML significa Hyper Text Markup Language,a linguagem de marcação padrão para criar páginas da Web. html é o elemento raiz de um HTML página. title um título para o Página(é mostrada na barra de título do navegador ou na guia da página). body o corpo do documento é todo o conteúdo visível como títulos, parágrafos, imagens, hiperlinks, tabelas, listas,etc. h1 um título grande. p um parágrafo negrito, itálico e sublinhado quando necessário.

Quais tipos de Mídias

(Voltar) O que são Formulários:

No HTML, podemos usar imagens (img) para exibir fotos e gráficos. Para áudio e vídeo para reproduzir sons e filmes. Com iframe, incorporamos conteúdos externos, como mapas e vídeos do YouTube. E com object, embed ou svg, adicionamos PDFs, animações e gráficos vetoriais.

O que são Tabelas

(Voltar) Quais tipos de Mídias:

São estruturas usadas para organizar e exibir dados em linhas e colunas, de forma semelhante a uma planilha do Excel. Principais elementos: table → cria a tabela. tr → define uma linha. td → define uma célula (dado comum). th → define uma célula de cabeçalho (fica em negrito/centralizada por padrão).

O html Semântico

(Voltar) O que são Tabelas:

HTML semântico é o uso de tags que têm significado e descrevem o papel do conteúdo na página. Exemplo: em vez de usar apenas div, utilizamos header, nav, main, article, section, footer etc. Isso melhora a organização do código, a acessibilidade (para leitores de tela) e o SEO (motores de busca entendem melhor a página). Resumindo: HTML semântico dá estrutura e sentido ao conteúdo, não apenas aparência.

A diferença sobre as listas

(Voltar) O html Semântico:

Lista não ordenada (ul) → os itens aparecem com marcadores (bolinhas, quadrados). Lista ordenada (ol) → os itens aparecem em ordem numérica ou alfabética. Lista de definição (dl) → usada para conceitos e descrições (como em dicionários).
