Elementos estudados até agora
Textos: títulos (<h1>...<h6>), parágrafos (<p>), negrito (<b> / <strong>), itálico (<i> / <em>).
Links: <a href="url">Texto</a>.
Imagens: <img src="imagem.jpg" alt="Descrição">
Listas: ordenadas (<ol>), não ordenadas (<ul>), definição (<dl>).
Tabelas: <table>, <tr>, <td>, <th>.
Mídias: <audio>, <video>, <iframe>.
Semântica: <header>, <nav>, <main>, <section>, <article>, <footer>.
Usar HTML semântico para dar significado ao conteúdo.
Incluir atributos de acessibilidade (ex: alt em imagens).
Manter o código indentado e organizado.
